# Task-to-owner map

Read [AGENTS.md](../AGENTS.md) first. This map helps discover owners; it neither creates authority nor replaces the root start-of-work reading gate.

| Concern | Owning source or route |
| --- | --- |
| Workflows, approval, independent review, completion | Root AGENTS; then the applicable governance playbooks |
| Research boundary, claim classes, vocabulary | [SCOPE](../SCOPE.md), [DOCTRINE](../DOCTRINE.md), [GLOSSARY](../GLOSSARY.md) |
| Source identity, evidence review, integration state and actual uses | [Source Registry](../evidence/SOURCES.md), original source and relevant evidence brief |
| Bibliography only | [REFERENCES](../REFERENCES.md); not a source-state database |
| Report argument | [Part 1](../report/01_the_illusion.md), [Part 2](../report/02_broken_mechanics.md), [Part 3](../report/03_the_aftermath.md) and their source dependencies |
| Operational response | [Protocol index](../protocols/README.md) and the owning protocol |
| New article draft | [Article index](../report/articles/README.md), scoped AGENTS, complete blueprint and manuscript |
| Article HTML/PDF transport | [Publishing guide](../tools/publishing/README.md), manifest, driver, configs, exporter, tests and workflow |
| Authorship and phrase provenance | [Terminology and Attribution](../TERMINOLOGY_AND_ATTRIBUTION.md) and documentary briefs |
| Repository artifact relationships | [Artifact Model](../ARTIFACT_MODEL.md) |
| Changed-path synchronization and CI | [PR process](pr-process-and-synchronization.md), trusted matrix, work record, validators and workflows |

Article drafts are proposed report synthesis, not an additional evidence tier. Rendered files are distribution surfaces, not new sources of conceptual authority. The article manifest does not own research validity, source verification or approval state. Unmerged PRs may identify related work, but their proposals do not become current policy by being linked here.

No full Repository Intelligence index, graph, benchmark, semantic-search service or UA-specific conformance model is introduced by this map. A future extension should demonstrate a navigation need and measurable benefit before adding another maintained control surface.
