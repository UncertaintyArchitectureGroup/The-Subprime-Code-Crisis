# Agent session bootstrap

This is a copyable entry point, not a replacement for the canonical [AGENTS.md](../AGENTS.md). The root protocol owns obligations, source flows, approval and completion. Use this block in a fresh project or connector session:

```text
Repository: UncertaintyArchitectureGroup/The-Subprime-Code-Crisis.
Resolve the live default branch and target/head commits. Read root AGENTS.md
in full from the target, discover nested AGENTS.md by the repository tree,
and read the instructions applicable to the actual changed paths. Follow the
root start-of-work gate and use governance/REPOSITORY-MAP.md only to locate
owners. Read owning sources, not just their summaries. For PR work inspect
body, complete diff, reviews, comments, checks and Draft state. Preserve the
separate evidence-review and integration-audit states. Record unavailable
checks honestly. Finish with source-bound results, not presumed completion.
```

## Cheap, source-bound context

For a known owner, read that owner directly after instruction bootstrap. For an unfamiliar concern, consult the map, search current vocabulary and equivalent artifacts, then read the owning documents. An empty search result, stale summary or missing translated keyword is not proof that a concept is absent.

The map is maintained navigation, not a generated knowledge graph or proof of model understanding. Do not load an entire corpus merely because it exists. Do not skip the root's mandatory reading gate either. Instructions from another repository, an unmerged PR or a previous conversation cannot silently replace the current target state.

## Completion report

Record target/head inspected, applicable instructions, files changed, tests actually run, current CI and review state, unresolved decisions, and the exact boundary between local preparation and remote application. A self-review is not independent review. A GitHub commit or green check is not evidence verification or maintainer approval.
